Entry for the make.fun bounty [Build a tiny stack virtual machine, 22 November 2026](https://make.fun/bounty/tiny-stack-vm-01-run-20261122).

`main.ts` (Node 22, standard library only) is a faithful interpreter for
make.fun's tiny stack instruction set: it loads a program, executes it on a
value stack with the specified semantics, and writes the result exactly as
the harness expects. On the kit's practice set it scores the full
1,000,000 (40/40 programs).
